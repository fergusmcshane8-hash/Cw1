# Cw1
The code was made and tested within Visual studio code using python. 
The line to run the program is Sudoku_Solver.py <Easy.txt>/ <Basic.txt>/ <Extreme.txt>.
There is 3 possible puzzles to solve each only require changing the file name on line 5 to the desired file. 
The program will run the basic sudoku option with the available puzzles being easy or extreme.
The external library required is import time, which is used to measure the speed of the program.
